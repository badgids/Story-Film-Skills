# Creative Production Spec

Read `../../references/CREATIVE_PRODUCTION_SPEC.md`.

1. Read existing brief, canon, bibles, decisions, evidence, resource constraints, production capabilities, and requested delivery scope.
2. Do not interview unless the existing material contains a true contradiction that prevents faithful synthesis.
3. Write `00_project/creative_production_spec.md` using the reference structure.
4. Preserve the project's vocabulary and stable IDs.
5. State acceptance in terms a human or validator can observe in the story, image, audio, video, film, document, campaign, or release package.
6. Distinguish locked requirements from preferences and deferred decisions. Put project-specific naming, prompt formatting, generation, review, handoff, and delivery rules under `Project Production Conventions`; do not add them to story canon.
7. Run project validation before treating the spec as ready for work-unit decomposition.
