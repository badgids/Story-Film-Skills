# Production Compass

Read `../../references/PRODUCTION_COMPASS.md` and `../../references/CREATIVE_DECISION_PROTOCOL.md`.

Use when the requested destination is larger than one agent session can responsibly specify.

1. Name the destination first.
2. Use `decision-tree-interview` breadth-first to expose only decisions that can be stated now.
3. Write `00_project/decision_map.json` and `00_project/decision_map.md`.
4. Work the ready decision frontier one node at a time.
5. Use factual research, cheap prototypes, or human discussion according to what the decision actually requires.
6. After resolving a decision, append it to `creative_decisions.jsonl`, update the map index, and graduate newly-visible fog into decision nodes only when their question is now precise.
7. Keep explicitly ruled-out work in out-of-scope, not in the unresolved frontier.
8. When the route is clear, hand off to `creative-production-spec` rather than continuing to execute production inside the map.
