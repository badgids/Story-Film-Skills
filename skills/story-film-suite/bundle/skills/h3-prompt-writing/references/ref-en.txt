REFERENCE LABELS

<Subject N>
Reusable visible content such as a person, object, environment, clothing, prop, interface, style, action, expression, or pose.

<Picture N>
A concrete image anchor such as first frame, keyframe, last frame, edited keyframe, or shot-planning/composition anchor.

<Video N>
A whole-video source used for editing, continuation, camera/cut/rhythm structure, or other temporal relationships.

<Audio N>
A standalone or enabled synchronized audio source used for exact reuse or reference.

Labels are numbered independently by type and keep the same meaning in every section.

SUMMARY

Use one short paragraph beginning with one or more actual task relationships, such as:
[reference generation]
[keyframe completion]
[video editing + audio reuse]
[video continuation + keyframe completion]
[audio reference]

Do not infer a task type merely because a file exists. Use the role the reference actually plays.

DETAILED DESCRIPTION

- Establish style in one or two sentences before [Shot 1].
- [Shot 1] has no cut timestamp.
- Later shots use [Shot N] At MM:SS.mmm, ...
- Insert reference labels naturally at the moments where their content or role actually applies.
- Use stable speaker IDs (S1), (S2), and so on.
- Dialogue and lyrics use <d>[Language] exact source content</d>.
- Preserve dialogue, lyrics, and visible text in their original language.
- Use the shared base-mode camera, dialogue-continuity, and sound rules.
- Describe composition, subject appearance/position, environment, lighting, action/state changes, camera, current sound, and exact reference use. Do not collapse the body into a plot summary.

STORY-FILM AUTHORITY

A reference label is not permission to broaden that asset's role. Identity-only, wardrobe-only, composition-only, temporal-only, audio-only, or other scoped references retain those scopes. When Story-Film authority and a style overlay conflict, Story-Film authority wins.
