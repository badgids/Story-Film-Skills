# Programmatic Video

Use for complex deterministic motion graphics, explainers, animated typography, maps, data-driven video, reusable title systems, or campaign templates.

1. Read `programmatic-video`, `design-system`, and relevant source artifacts.
2. Create portable `COMP-###` compositions first.
3. Use `motion-graphics` instead when simple FFmpeg overlays are sufficient.
4. If Remotion is selected, generate the adapter project without bundling or silently installing Remotion.
5. Respect Remotion license boundaries before install/render execution.
6. Register any rendered output as a media candidate and run QC.
7. Feed approved renders into film, trailer, social, or editor-project timelines like any other approved media.

Done when the portable composition is complete and any requested implementation target is generated or truthfully blocked.
