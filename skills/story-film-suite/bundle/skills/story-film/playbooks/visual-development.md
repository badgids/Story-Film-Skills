# Visual Development

1. Read brief and canon.
2. `character-bible` or `world-bible` when visual facts are not locked.
3. `visual-bible`: define the visual language and any moodboard briefs.
4. `reference-assets`: define roles, preserve rules, variants, provenance, coverage plans, and approval state before generating continuity-critical assets.
5. `generation-pack`: make image briefs for requested characters, locations, props, costumes, style boards, moodboard frames, or keyframes.
6. Use `krea-2` for open exploration or `qwen-image-2512` for production stills and exact text.
7. Use `qwen-image-edit-2511` for controlled revisions or reference combination.
8. For turnarounds and location coverage, write the native coverage plan and self-contained prompts. Create a contact-sheet plan when multiple results need review.
9. `prompt-qc`.

Done when prompts contain stable IDs, approved references are versioned, preserve rules are explicit, the visual bible is internally coherent, and no visual fact conflicts with canon.
