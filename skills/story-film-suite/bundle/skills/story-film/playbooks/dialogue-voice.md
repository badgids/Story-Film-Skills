# Dialogue and Voice

1. Read screenplay dialogue and character bible.
2. `dialogue-voice`: create voice bible and voice cues.
3. `qwen3-tts`: choose custom voice, voice design, or clone mode per character.
4. If inventing a reusable voice, design a reference clip and then use it as clone reference.
5. `prompt-qc` for exact line text and character mapping. Done when every spoken line maps to one `VOICE-###` identity and exact screenplay text unless an approved dialogue revision exists.
