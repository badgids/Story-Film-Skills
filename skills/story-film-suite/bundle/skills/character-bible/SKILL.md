# Character Bible

## Workflow

1. Read core contract, style rules, brief, and story architecture.
2. Assign stable `CHAR-###` IDs.
3. For each consequential character, record: role, objective, fear or limit, contradiction, pressure behavior, relationship map, private knowledge, speech pattern, physical identifiers, wardrobe logic, props, arc start and end.
4. Keep biography only when it changes present behavior.
5. Write `01_story/characters.md`.
6. Update `00_project/canon.json` with locked identity and continuity facts.

## Done

Every recurring character can be recognized in prose, dialogue, casting description, still-image prompt, and video prompt from the same saved facts.
