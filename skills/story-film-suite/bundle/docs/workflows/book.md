## Use this workflow

Use the `idea-to-book` playbook when the main product is a novel, novella, or narrative book.

## Main steps

1. Define the purpose, audience, genre, and scope.
2. Build the story architecture.
3. Define characters and world rules.
4. Build beats and a chapter plan.
5. Write one chapter at a time.
6. Save chapter state after each approved chapter.
7. Run continuity and story review at planned gates.
8. Revise the full book after a complete draft exists.

Do not write the whole book in one model response.

## Adapt the book later

Keep stable story facts and chapter state.

Use the screenplay adaptation workflow when you want to turn the book into a film.
