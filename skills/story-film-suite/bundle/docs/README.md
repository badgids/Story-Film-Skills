# Story-Film Skills Documentation

[Repository README](../README.md) | [Quick start](getting-started/quick-start.md) | [Glossary](reference/glossary.md)

Story-Film Skills helps an AI agent plan and make stories, books, screenplays, audio, images, video, and films. It can manage a project from the first idea to the final film package.

These documents use controlled, simple English. Sentences are short. Terms stay consistent. Instructions use one main action at a time.

> Note: The writing follows important ASD-STE100 controlled-English principles and ELI5 teaching goals. This documentation is not an official ASD-STE100 certification.
