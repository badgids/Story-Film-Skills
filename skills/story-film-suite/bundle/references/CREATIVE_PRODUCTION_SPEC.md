# Creative Production Specification

The Story-Film specification is a durable synthesis of decisions already made. It is not another interview.

Default path: `00_project/creative_production_spec.md`.

Recommended sections:

## Destination
What finished result the user expects, including story/book/image/audio/video/film/release scope.

## Audience Experience
What the audience should understand, feel, anticipate, and remember.

## Source and Canon
Authoritative source artifacts, locked facts, reference IDs, and evidence requirements.

## Creative Requirements
Story, character, world, dialogue, visual, performance, sound, music, and editorial requirements relevant to the scope.

## Production Requirements
Generation routes, production capabilities, editable-project needs, output formats, resource constraints, and human approval gates.

## Project Production Conventions
Durable project-specific naming, prompt formatting, generation, handoff, review, and delivery conventions that affect production execution but are not story canon. Preserve the user's exact rule wording when it is already clear.

## User Outcomes
A long numbered list in the form: `As <participant>, I need <result>, so that <benefit>.` Participants may include the audience, writer, director, editor, performer, compositor, sound designer, marketing operator, or end user.

## Acceptance Decisions
Externally observable conditions that prove the requested creative/production behavior exists. Prefer final artifact behavior and visual/audible outcomes over internal implementation details.

## Validation Strategy
Which existing Story-Film validators, QC gates, continuity checks, media probes, or human approvals demonstrate acceptance.

## Out of Scope
Explicit boundaries.

## Open or Deferred Decisions
Only unresolved items that genuinely remain.

## Further Notes
Constraints and rationale that do not belong elsewhere.

Do not include transient file paths unless the path itself is part of the portable artifact contract. Prefer stable artifact names and IDs.
