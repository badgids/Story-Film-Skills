# Reference Sheet Contract

Reference sheets are continuity assets, not decorative collages.

Supported plan types include `character-reference`, `location-reference`, and `prop-reference`. A plan identifies one authoritative subject, desired views, optional functional views, and a coherence policy.

For props, functional/mechanical views are first-class. A latch, lever, control, articulated part, container closure, weapon mechanism, tool interface, or vehicle control may need a view that explains how it works rather than another beauty angle.

`single-generation-sequence` means the views should be derived from one coherent generation sequence where the active workflow supports it. `staged-edit` means each pass must preserve the prior approved identity while adding only the requested grounding layer.
