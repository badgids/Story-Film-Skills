# Reference Development

1. Read brief, canon, continuity, planned scenes, and shot needs.
2. `reference-assets`: create the minimal reference manifest and missing-reference report.
3. Create native character turnaround plans, location coverage plans, prop briefs, style references, keyframe references, voice references, or music references only where production needs them.
4. `visual-bible` when the reference set needs a shared visual language or moodboard brief.
5. Use the appropriate image, video, voice, or music adapter to write generation prompts.
6. Create `contact_sheet_plan.json` when candidates need structured comparison.
7. Run `prompt-qc` on generated prompt documents.
8. Approve reference versions only after continuity-critical traits are inspectable.

Done when every requested reference has a stable `REF-###`, explicit role, preserve rules, provenance, approval state, and a standalone generation or review plan.
