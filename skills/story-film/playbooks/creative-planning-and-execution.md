# Playbook: Creative Planning and Production Execution

Use when an idea or large creative request needs to become a durable Story-Film plan and then bounded executable work.

## Steps

1. Read `creative-pressure-test` and use `decision-tree-interview` to expose consequential creative and production assumptions in dependency order.
2. If the project is likely to span many sessions or the route is still unclear, read `production-compass` and maintain the decision frontier until the destination is clear enough to specify.
3. Read `documented-creative-discovery`. Persist settled decisions, canon implications, evidence links, and project vocabulary without duplicating existing bibles or source documents.
4. Read `creative-production-spec`. Synthesize what is already settled into `00_project/creative_production_spec.md`; do not restart the interview merely because a spec is requested.
5. Read `production-work-units`. Decompose the approved destination into complete `UNIT-###` slices with blocker edges, acceptance criteria, and validation gates. Write both JSON and Markdown work-unit views.
6. Initialize or refresh the Pi pipeline Todo from the selected execution playbook.
7. Read `production-executor`. Execute only a ready work-unit frontier item, validate it, and keep failures non-advancing.
8. When a step requires an unavoidable human-only action, use `guided-production-wizard`; otherwise use the available deterministic tool instead of delegating agent-capable work to the user.
9. Before context compaction, model switch, resource handoff, or session end, use `session-bridge` to refresh the compact durable handoff.

## Done

The destination is either fully produced through accepted work units, or the remaining frontier/blocker is explicit in project state and the next session can continue without reconstructing decisions from chat.
