# Creative Review

Use when the user wants diagnosis, audience reaction, character pressure testing, or a disputed creative decision rather than a new draft.

1. Read the requested artifact and its authoritative upstream context.
2. Use `story-review` for analytical prose diagnosis.
3. Use `character-sim` only when character voice, knowledge, or relationship behavior needs a pressure test.
4. Use `audience-sim` when the question is what a defined reader or viewer experiences rather than what a critic thinks should change.
5. Use `crew-review` only for a consequential dispute or a bounded correction loop.
6. If the review changes accepted direction, apply the change through the owning revision skill and run `project-impact`.
7. Update `story-state` if the accepted change alters chronology, knowledge, questions, promises, life state, or props.

Done when the requested review question is answered without mixing diagnosis, simulation, and rewriting into one opaque pass.
