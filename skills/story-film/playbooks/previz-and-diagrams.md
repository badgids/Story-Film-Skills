# Previz and Production Diagrams

1. Read screenplay scenes, director book, canon, continuity, and shot scope.
2. `production-diagrams`: create only the relationship, timeline, geography, blocking, eyeline, shot-flow, reference, or dependency diagrams that answer a current production question.
3. `previz-plan`: create portable scene geometry, actor paths, entrances, exits, obstacles, eyelines, camera setups, screen direction, and cut order when spatial planning is useful.
4. Keep verified geometry separate from assumptions.
5. Update shot design only when the diagram or previz plan reveals a real staging or camera problem.
6. Run `continuity-check` at the changed scene boundary.

Done when the requested spatial or structural question is resolved using native project files and any resulting shot changes are reflected downstream.
