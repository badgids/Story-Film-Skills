# Production Documents

Use when the project needs editable or printable production paperwork or release documents.

1. Identify the authoritative source artifacts and requested audience.
2. Route tables, trackers, budgets, schedules, and matrices to `production-documents` XLSX output.
3. Route editable narrative packets, call sheets, reports, press kits, and director books to DOCX.
4. Route fixed review/delivery packets to PDF and `pdf-toolkit` for QA/manipulation.
5. Use `design-system` for public-facing visual consistency where appropriate.
6. Add `DOC-###` manifest records and source IDs.
7. Run structural and visual/recalculation QA available in the current runtime.
8. Add requested public documents to `release-package`.

Done when requested documents exist in the declared formats and pass applicable QC.
