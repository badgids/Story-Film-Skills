# Idea to Story

1. `story-brief`: save `00_project/brief.md`.
2. `story-architecture`: save `01_story/logline.md` and `01_story/story_bible.md`.
3. `character-bible`: save `01_story/characters.md` and update canon.
4. `world-bible`: save `01_story/world.md` and update canon if the setting needs persistent rules.
5. `beat-sheet`: save `01_story/beat_sheet.md`.
6. `scene-outline`: save `01_story/scene_outline.md`.
7. `write-story`: save `01_story/story.md`.
8. `revise-story`: run one structural and one prose pass.
9. `continuity-check`: no unresolved canon conflicts.
10. Run `check_style.py`. Done when the story is complete and all required IDs resolve.
