# Evidence-Backed Project

Use for documentaries, historical stories, technical explainers, fact-heavy fiction, press kits, or campaigns where public claims need source traceability.

1. Run `story-research` for exploratory research.
2. Run `evidence-research` for claims likely to appear in narration, on-screen text, documents, or publicity.
3. Keep `CLAIM-###` status, confidence, sources, disagreements, and adoption explicit.
4. Update canon only after the project adopts a research finding.
5. Before public copy or documents, validate the claim ledger.
6. Route campaign writing through `campaign-brand`, `content-repurpose`, and `social-copy` so public claims remain traceable.

Done when creative use and public factual use are distinguishable and every material public claim has evidence state.
