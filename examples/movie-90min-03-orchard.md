# MOVIE-90M-003: The Glass Orchard

**Production level:** 90+ minute movie  
**Target runtime:** at least 90 minutes, target about 110 minutes  
**Purpose:** Example and end-to-end test prompt for Story-Film Skills.

## Prompt

```text
Use Story-Film Skills to create a complete original animated family fantasy feature with a final runtime of at least 90 minutes. Target about 110 minutes.

Working title: The Glass Orchard

Genre: Family fantasy adventure.

Premise: In a valley where families grow glass fruit that stores memories as light, a practical young courier discovers that the oldest orchard is going dark. When a storm breaks thousands of memory-fruits, fragments of strangers' memories begin appearing in the wrong people. The courier joins a retired orchard keeper and an overconfident young inventor to carry one unbroken seed to the mountain greenhouse where the first glass tree was grown. Along the way, they learn that restoring every memory exactly may not be possible or desirable.

Create an emotionally rich adventure for a broad family audience. Use humor, danger, wonder, grief, and hope without becoming frightening for young viewers. Give the antagonist or opposing force an understandable goal rather than simple evil.

Design an original visual world with clear rules for glass fruit, stored memories, light, weather, tools, transport, clothing, creatures, and geography. Track which memories belong to which characters, which fragments move between people, what each character knows, the condition of the seed, travel progress, injuries, costume changes, and the rules of the magic.

Use sequence-level feature production, context shards, long-range continuity, production health checks, generation budgeting, resource-safe ComfyUI execution, selective batch recovery, take selection, sequence editorial, final reconciliation, audio finishing, original music direction, songs only if they are created specifically for this project, captions, delivery QC, final master, completeness audit, trailer, artwork, social campaign, and release package.

All characters, creatures, music direction, environments, symbols, and designs must be original. Do not imitate a protected animation studio, existing franchise, or living artist.

Testing goal: stress a large visual bible, many recurring environments and props, magical-rule continuity, character-state continuity, feature-scale generation, music and sound, animation-style consistency, and the final completeness gate.
```

## Test notes

Use the prompt without changes for a full production test. For a faster planning test, use the test modes in [Examples and test prompts](README.md).
