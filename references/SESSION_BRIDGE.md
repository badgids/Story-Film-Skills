# Session Bridge

A session bridge gives a fresh agent the minimum authoritative context required to continue Story-Film work.

Default human-readable artifact: `00_project/HANDOFF.md`.

It should contain:

- destination/current scope
- active playbook and exact Todo target
- active `UNIT-###` or `DEC-###` when applicable
- current blocker
- exact next action
- authoritative artifacts to read next
- recently changed authoritative files
- resource-handoff state if ComfyUI is running without the LLM
- suggested Story-Film skills for the next session

Do not duplicate long specs, bibles, decision maps, or manifests. Link them by project-relative path. Redact secrets and credentials.
