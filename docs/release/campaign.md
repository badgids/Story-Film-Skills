## Trailers and teasers

Trailer work has its own planning, editorial, QC, and delivery state. It does not silently modify the feature timeline.

## Social campaign

Social outputs can use different duration and aspect ratios. Reframing and cutdowns must still point back to approved source media.

## Brand voice

`brand_voice.json` stores stable campaign language rules. Use it to keep titles, descriptions, calls to action, and campaign tone consistent.

## Content lineage

`CONTENT-###` records show which source artifact produced each derived campaign item.

This prevents a social post from slowly changing the facts or story of the film.

## Release package

The release manifest declares required deliverables. Package collection verifies required files and can produce checksums.

Do not mark a required delivery item complete because a similar file exists elsewhere.
